Приватность и AdBlock

Блокировка рекламы и трекеров
Работает на уровне сессии для всех вкладок
Косметическая фильтрация
Скрывает рекламные блоки и пустые рекламные контейнеры на страницах. Действует на новых страницах, работает только при включённой блокировке рекламы
Заблокировано запросов
С запуска браузера
0
Красивый стиль поисковика
Страницы поиска оформляются под тему браузера
Только HTTPS
Адреса http:// сначала открываются по https://. Если сайт не поддерживает HTTPS, браузер предупредит, и можно перейти на свой риск (исключение действует до закрытия браузера)
Блокировать сторонние (third-party) cookies
Cookie и Set-Cookie не отправляются и не принимаются в кросс-сайтовых подзапросах, хранилище разделяется по сайту верхнего уровня. Может нарушить вход через виджеты и встроенные формы. Разделение хранилища применится после перезапуска браузера
Очищать ссылки от трекинговых меток
Убирает utm_*, fbclid, gclid, yclid, mc_eid, _openstat, roistat* при переходах. Ссылки авторизации (OAuth: code, state и др.) и POST-запросы не затрагиваются
Защита от цифрового отпечатка (Fingerprinting) в Инкогнито
Только для окна Инкогнито: единые заголовки Client Hints (Sec-CH-UA*), язык запросов en-US,en;q=0.9 и letterboxing — область страницы округляется вниз до кратных 100×100 px и центрируется, чтобы скрыть точное разрешение экрана. Строгий режим может нарушать работу отдельных сайтов: сайты на английском вместо вашего языка, поля по краям страницы, неверная вёрстка или отказ в доступе
Открывать Инкогнито в отдельном окне
Включено: Ctrl+Shift+N открывает отдельное окно Инкогнито рядом с обычным. Выключено: режим переключается в текущем окне, обычные вкладки возвращаются при выходе из Инкогнито
Подсказки поисковика
Отправлять вводимый текст поисковику для подсказок в адресной строке (в Инкогнито отключено)

DNS-over-HTTPS

Режим DoH
«Автоматический» — DoH, при сбое откат на системный DNS. «Строгий» — только DoH без отката: если сервер недоступен, сайты не откроются. Применяется сразу
Провайдер DoH
Сервер, которому отправляются DNS-запросы
Свой адрес DoH
Только https://, например https://dns.example.com/dns-query

Свои правила фильтрации

Поддерживаются сетевые правила и исключения (синтаксис AdGuard / uBlock / ABP), например ||example.com^ и @@||site.com^. Косметические правила (##, #@#) применяются, пока включена косметическая фильтрация. По одному правилу в строке, комментарии начинаются с !.

AdBlock выключен: правила сохранятся и применятся при включении.

Очистка данных

В Инкогнито «Кэш» и «Cookies и данные сайтов» очищаются только для текущего инкогнито-сеанса (он и так удалится при выходе). «История» недоступна: в Инкогнито она не ведётся, а историю обычного режима отсюда не стереть — выйдите из Инкогнито и очистите её там.

Кэш
Файлы и изображения сайтов. Входы в аккаунты сохранятся
История
Список посещённых сайтов (подсказки в адресной строке)
Cookies и данные сайтов
Cookies, localStorage, IndexedDB, service workers. Вы выйдете из аккаунтов на сайтах

Сеть и Прокси

Режим прокси
«Системный» — настройки ОС, «Напрямую» — без прокси, «Ручной» — свой сервер. Применяется сразу, открытые соединения переустанавливаются
Протокол
Хост
Имя или IP-адрес сервера, например proxy.example.com
Порт
Не использовать прокси для
Через запятую: localhost,127.0.0.1,*.example.com,10.0.0.0/8. Можно оставить пустым
Применять только в окнах Инкогнито
Обычный режим остаётся на системном соединении, Инкогнито идёт через указанный прокси
Если прокси требует логин и пароль, браузер запросит их при первом обращении (для HTTP-прокси). SOCKS5 с авторизацией Chromium не поддерживает

Пароли и автозаполнение

В Инкогнито менеджер паролей недоступен: сохранённые пароли обычного режима здесь не показываются и не меняются.

Безопасное хранилище ОС недоступно (Windows DPAPI / системная связка ключей). Новые пароли не сохраняются, а показать сохранённые может не получиться.

Расширения

Поддерживаются распакованные расширения Chrome (папка с manifest.json). Доступ к файлам file:// им отключён. Часть API Chrome в Electron не реализована, поэтому некоторые расширения могут работать не полностью.
